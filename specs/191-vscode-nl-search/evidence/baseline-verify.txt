## Environment constraint

This cloud session's firewall blocks `registry.npmjs.org`
(`HTTP 403 host_not_allowed` — confirmed via `curl -I`). Consequently
`pnpm install` cannot hydrate `node_modules/` in-session, and commands
such as `pnpm --filter @debrief/components typecheck` and
`pnpm -r test` fail at the workspace-resolution / install step (not at
the code under test).

The `task` binary is also not on `$PATH` in this container, so
`task verify` is unavailable; the CLAUDE.md fallback commands also
depend on `pnpm install` succeeding.
