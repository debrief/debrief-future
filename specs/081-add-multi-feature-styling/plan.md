# Implementation Plan: Add MultiPoint and MultiPolygon Feature Schemas

**Branch**: `081-add-multi-feature-styling` | **Date**: 2026-02-13 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/081-add-multi-feature-styling/spec.md`

## Summary

Add two missing GeoJSON geometry classes (`GeoJSONMultiPoint`, `GeoJSONMultiPolygon`) and corresponding Feature types (`MultiPointFeature`, `MultiPolygonFeature`) to the LinkML master schema. The existing styling classes (`PointProperties`, `PolygonProperties`) already document multi-geometry support but lack the geometry classes and feature types to wire them up. This feature closes the gap, enabling tools currently in development to return multi-point and multi-polygon results as validated, styled GeoJSON Features.
