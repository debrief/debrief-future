Shipped: Saved Filter Configurations for Debrief

Analysts can now save, restore, and delete named filter configurations in the STAC Browser filter bar. Filter sets persist across sessions — no more rebuilding the same combination every time.

Two controls added to the existing filter bar:
- Save button with name prompt (or auto-generated names)
- Historic Filters dropdown with restore and delete

Built with a platform-agnostic storage interface — same components work in VS Code and the browser. 120 unit tests, E2E tests across three theme variants.

Part of the STAC Browser Discovery UI epic (E08). Combined with the CQL2 filter engine and lozenge-based filter bar, analysts now have a complete workflow for building, refining, and reusing exercise filters.
