# Quickstart: Buffer Zone Generator

**Feature**: 080-buffer-zone-generator

## Overview

The buffer-zone-generator tool creates 3 concentric detection-likelihood buffer polygons around a track feature. It uses a stub sensor model returning zones at 3 nm (75%), 6 nm (50%), and 12 nm (25%).

## Running the Tool

### Via Python (direct invocation)

```python
from debrief_calc.models import ContextType, SelectionContext
from debrief_calc.tools.sensor.detection.buffer_zone_generator import buffer_zone_generator

track = {
    "type": "Feature",
    "id": "track-001",
    "geometry": {
        "type": "LineString",
        "coordinates": [[-4.5, 50.2, 0, 1705305600000], [-4.4, 50.3, 0, 1705309200000]]
    },
    "properties": {"kind": "TRACK", "name": "HMS Example"}
}

context = SelectionContext(type=ContextType.SINGLE, features=[track])
zones = buffer_zone_generator(context, {})
# Returns: list of 3 GeoJSON Feature dicts (Polygon geometries)
```

### With Custom Distances

```python
zones = buffer_zone_generator(context, {
    "distance_1_nm": 2.0,
    "distance_2_nm": 8.0,
    "distance_3_nm": 15.0,
})
```

## Key Design Patterns

1. **Sensor model is swappable**: `sensor_model.py` defines a Protocol; pass a different implementation to test or replace.
2. **Convex hull for polygons**: Each zone is generated by offsetting track vertices at 36 bearings and computing the convex hull.
3. **Nautical miles**: User-facing distances in nm, converted internally to km for Vincenty formula (1 nm = 1.852 km).
4. **Concentric zones**: Each polygon fully encloses the smaller zones (not annular rings).
