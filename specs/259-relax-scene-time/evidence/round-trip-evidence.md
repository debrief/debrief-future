## Walked example

Pydantic write → JSON → Pydantic read of `valid/storyboard-tied-timestamps.json`:

```python
from debrief_schemas import SceneFeature
from pathlib import Path
import json

raw = json.loads(Path("shared/schemas/src/fixtures/valid/storyboard-tied-timestamps.json").read_text())
# Three Scenes at the same timestamp, creation_order = 0, 1, 2
for f in raw["features"]:
    if f["properties"]["kind"] != "STORYBOARD_SCENE":
        continue
    scene = SceneFeature(**f)
    serialised = scene.model_dump_json(by_alias=True)
    reparsed = SceneFeature.model_validate_json(serialised)
    assert reparsed.properties.creation_order == scene.properties.creation_order
    assert reparsed.properties.timestamp == scene.properties.timestamp
```

All three Scenes round-trip identity-preserved.
