## `TimeFilter`

### Bounded on both sides

```
Python → JSON: {"start":1704067200000,"end":1704153600000}
JSON → Python: equal to input    ✅
```

### Unbounded (both sides missing — canonical "no filter")

```
Python → JSON (exclude_none=True): {}
JSON → Python: TimeFilter(start=None, end=None)    ✅
```

Consumers use `value != null` checks (FR-021), so the `{}` payload is
equivalent to explicit nulls — matching the load-time helper in
`services/session-state/src/persistence/load.ts` that coerces legacy nulls to
undefined on the runtime side.
