Shipped: AI-assisted epic breakdown for large features.

When a feature is too big for a single backlog item, you need structured decomposition. Our new `/epic` command uses Opus as both Business Analyst and Technical Architect.

Feed it a spec (text, local file, or GitHub URL). Get back 3-10 independently valuable items—properly sequenced, complexity-estimated, and ready for implementation.

The key insight: breakdown quality matters more than breakdown speed. Opus-level reasoning catches dependencies and risks that cheaper models miss.

How it works:
- Vertical slices over horizontal layers
- Infrastructure first (if it unblocks)
- Research spikes early (to reduce uncertainty)
- Full traceability via `[E01]` prefixes

Each item links back to its parent epic. GitHub issues created automatically (with offline fallback to local files).

First test case: our Storyboarding Briefings feature. Complex enough to validate the approach, documented enough to feed the analyzer.
