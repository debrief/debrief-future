Select two tracks on the map. Instantly see the analysis tools that work with two tracks. No hunting through menus, no guessing.

This week I'm integrating context-sensitive tool discovery into the Future Debrief VS Code extension. The matching logic (built and tested in isolation via Storybook) now connects to real selection state. Three access patterns — sidebar panel, right-click menu, keyboard commands — so analysts work however suits them.

The detail I'm most pleased with: enabling "show inactive tools" reveals what you *could* run with a different selection, with explanations like "Requires 2 tracks (1 selected)". Analysts learn the system's capabilities while working.

Every result carries provenance metadata tracing back to source features and the exact tool version. The Constitution requires it; I think analysts will appreciate it.
