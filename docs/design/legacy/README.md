# Classic Debrief reference screenshots

Reference images for the heritage section of `docs/ui-designer-brief.md`
(Section 3 and Appendix E). They were supplied by the project lead from
the Debrief v3 user guide and product imagery; drop the PNG files into this
folder under the names below. The brief describes each image in text so it
reads without them.

| # | Expected file | Content |
|---|---|---|
| 01 | `01-v3-workbench.png` | Full v3 workbench: Time Controller, Track Tote and Outline in the left column, plot with bathymetric chart, two XY plots (Range vs Time, B-Rate vs Time) bottom-right |
| 02 | `02-time-controller.png` | Time Controller: seven-button transport, LED-style DTG readout, scrub slider, dual-thumb time-period selector (120500 to 121145) |
| 03 | `03-track-tote.png` | Track Tote (user guide fig 4.1): Range, Bearing, Rel Brg, Brg Rate, ATB, Speed, Course, Depth, Time for COLLINGWOOD and NELSON with a units column |
| 04 | `04-outline.png` | Outline view: layer tree with Visibility column, select / make-primary (1) / make-secondary (2, +2) / show-hide toolbar |
| 05 | `05-mouse-modes.png` | Mouse mode buttons (guide section 2.2): Drag Track Segment, Drag Component, Drag Whole Feature, Pan, Range Bearing, Zoom In |
| 06 | `06-click-buttons.png` | Click buttons (guide section 2.3): Zoom Out, Fit to Window, Refresh View |
| 07 | `07-chart-overview-workbench.png` | Chart Overview inset and the full Tactical Analysis perspective (guide fig 2.2) with NELSON and COLLINGWOOD on a black canvas |
| 08 | `08-properties-view.png` | Properties sheet (guide fig 3.1): Format and Misc groups |
| 09 | `09-stacked-dots.png` | Stacked Dots / Bearing Residuals view (guide fig 3.2) with Translate, Rotate, Stretch, Shear drag modes and the track-shifting preconditions |
| 10 | `10-chart-features-menu.png` | Chart Features menu (guide fig 3.3): Scale, Time Display, grids, CoastLine, ETOPO, Chart Library, VPF, Natural Earth |
| 11 | `11-drawing-toolbar.png` | Drawing toolbar (guide fig 3.13) and the Misc / target-layer note |
| 12 | `12-grid-editor.png` | Grid Editor (guide fig 3.28): tabular sensor cuts with a linked Frequency chart beside the map |
| 13 | `13-tote-text.png` | Tote semantics (guide section 4.1.1): primary / secondary behaviour, annotations on the tote |
| 14 | `14-time-variable-plot.png` | Time-variable plot with tracker bar and waterfall mode (guide figs 4.10, 4.11) |
| 15 | `15-symbology.png` | Symbols provided by Debrief, indexed SVG symbols, non-indexed SVG symbols (guide figs 6.1 to 6.3) |
