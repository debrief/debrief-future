# Generate TMA from Infill

> Convert an infill track segment into a TMA segment with estimated course and speed.

## MCP

**Description**: Converts an infill track segment (interpolated positions between two known points) into a TMA (Target Motion Analysis) segment by computing average course and speed from the infill positions, and re-typing the segment as an absolute TMA solution.

**When to use**: When the user has an infill segment (generated by interpolation between two track points) and wants to promote it to a formal TMA segment with course/speed estimates for further analysis or track reconstruction.

**Parameters**:
- `features`: FeatureCollection containing one or more TRACK_SEGMENT features with `segment_type = "INFILL"`

**Returns**: ToolResponse containing one TMA_SEGMENT feature per input infill segment, with estimated course, speed, and quality metrics.

## Inputs

**Schema**: `shared/schemas/src/linkml/geojson.yaml#TrackSegmentFeature`

**Constraints**:
- At least one feature with `kind == "TRACK_SEGMENT"` and `segment_type == "INFILL"` required
- Each infill segment must contain at least 2 positions to calculate course and speed
- Each position must have `time`, `coordinates`, `course`, and `speed` properties

**Defaults**:
- None; all inputs are required

## Outputs

Returns a **ToolResponse** with one addition content item per infill segment.

**Response Schema**: `specs/041-document-tool-results/data-model.md#AdditionResult`

**Result Type**: `addition/analysis/tma_segment`

**Content Items**: One `AdditionResult` per infill segment containing:
- `type`: "resource"
- `uri`: `feature://{generated-tma-id}`
- `mimeType`: "application/geo+json"
- `text`: Serialized TMA_SEGMENT GeoJSON Feature

**Annotations** (on each content item):
- `debrief:resultType`: `"addition/analysis/tma_segment"`
- `debrief:sourceFeatures`: IDs of the source infill segment(s)
- `debrief:label`: `"Converted infill segment to TMA segment ({n} positions, avg course={c}, avg speed={s} kts)"`

## Algorithm

```pseudocode
FUNCTION generate_tma_from_infill(features: FeatureCollection) -> ToolResponse:
    // Validate inputs
    IF features IS NULL OR features.features IS EMPTY:
        RETURN build_error("Input features required", "invalid_input", [])
    END IF

    results = empty list

    FOR EACH feature IN features.features:
        // Filter for infill segments only
        IF feature.properties.kind != "TRACK_SEGMENT":
            CONTINUE
        END IF

        IF feature.properties.segment_type != "INFILL":
            RETURN build_error(
                "Input segment must be of type INFILL, but found " + feature.properties.segment_type,
                "invalid_input",
                [feature.id]
            )
        END IF

        positions = feature.properties.positions

        // Require at least 2 positions for course/speed calculation
        IF positions IS NULL OR LENGTH(positions) < 2:
            RETURN build_error(
                "Infill segment must contain at least 2 positions to calculate course and speed",
                "insufficient_data",
                [feature.id]
            )
        END IF

        // Calculate average course and speed
        sum_course = 0
        sum_speed = 0
        FOR EACH pos IN positions:
            sum_course = sum_course + pos.course
            sum_speed = sum_speed + pos.speed
        END FOR
        avg_course = ROUND(sum_course / LENGTH(positions), 1)
        avg_speed = ROUND(sum_speed / LENGTH(positions), 1)

        // Calculate course variance for quality assessment
        course_variance = calculate_variance(positions, "course")
        speed_variance = calculate_variance(positions, "speed")

        // Build TMA positions with floating-point course/speed
        tma_positions = empty list
        FOR EACH pos IN positions:
            tma_positions.append({
                time: pos.time,
                coordinates: pos.coordinates,
                course: FLOAT(pos.course),
                speed: FLOAT(pos.speed)
            })
        END FOR

        // Build TMA feature properties
        tma_properties = {
            kind: "TMA_SEGMENT",
            segment_type: "ABSOLUTE",
            platform_id: "TMA-FROM-INFILL",
            platform_name: "TMA from infill segment",
            parent_track_id: feature.properties.parent_track_id,
            source_segment_id: feature.id,
            start_time: feature.properties.start_time,
            end_time: feature.properties.end_time,
            estimated_course: avg_course,
            estimated_speed: avg_speed,
            positions: tma_positions,
            style: {
                line: {stroke: true, color: "#FF6600", weight: 2, opacity: 0.8, dashArray: "5,5"}
            }
        }

        // Add variance metrics and quality warning if course varies significantly
        COURSE_VARIANCE_THRESHOLD = 10.0
        IF course_variance > COURSE_VARIANCE_THRESHOLD:
            tma_properties.course_variance = ROUND(course_variance, 1)
            tma_properties.speed_variance = ROUND(speed_variance, 2)
            tma_properties.quality_warning = "High course variance (" + ROUND(course_variance, 1) + " deg) in infill segment; TMA solution may be unreliable"
            tma_properties.style.line.opacity = 0.5
        END IF

        // Build the TMA Feature
        tma_id = "tma-from-infill-" + DERIVE_SUFFIX(feature.id)
        tma_feature = {
            type: "Feature",
            id: tma_id,
            geometry: feature.geometry,
            properties: tma_properties
        }

        // Build label
        label = "Converted infill segment to TMA segment (" + LENGTH(positions) + " positions, avg course=" + avg_course + ", avg speed=" + avg_speed + " kts)"
        IF course_variance > COURSE_VARIANCE_THRESHOLD:
            label = label + " WARNING: high course variance"
        END IF

        results.append(build_addition(
            features: [tma_feature],
            result_subtype: "analysis/tma_segment",
            source_feature_ids: [feature.id],
            label: label
        ))
    END FOR

    IF results IS EMPTY:
        RETURN build_error("No INFILL segments found in input", "invalid_input", [])
    END IF

    RETURN build_response(results)
END FUNCTION

FUNCTION calculate_variance(positions: list, field: string) -> float:
    n = LENGTH(positions)
    IF n < 2:
        RETURN 0.0
    END IF
    sum = 0
    FOR EACH pos IN positions:
        sum = sum + GET_FIELD(pos, field)
    END FOR
    mean = sum / n
    sum_sq_diff = 0
    FOR EACH pos IN positions:
        diff = GET_FIELD(pos, field) - mean
        sum_sq_diff = sum_sq_diff + (diff * diff)
    END FOR
    RETURN SQRT(sum_sq_diff / n)
END FUNCTION
```

### Complexity

- **Time**: O(n * m) -- iterates over n infill segments with m positions each
- **Space**: O(n * m) -- stores all TMA positions in the output

## Edge Cases

| Scenario | Expected Behavior |
|----------|------------------|
| Empty feature collection | Return error response: `invalid_input`, "Input features required" |
| Segment type is not INFILL (e.g., PLAN) | Return error response: `invalid_input`, specifying expected vs actual segment type |
| Single position in infill segment | Return error response: `insufficient_data`, "must contain at least 2 positions" |
| High course variance across positions | Produce TMA segment with `quality_warning`, reduced opacity, and variance metrics |
| Constant course and speed | Produce clean TMA segment with no quality warning |
| Missing `parent_track_id` | Produce TMA segment with null parent_track_id |

## Examples

### Basic Usage

**Input**: `generate-tma-from-infill.basic.input.json`
**Output**: `generate-tma-from-infill.basic.output.json`

Description: Converts a straight-line infill segment (6 positions, constant course 180, speed 8 kts) into a TMA segment with avg course=180.0 and avg speed=8.0.

### Complex: Varying Course with Quality Warning

**Input**: `generate-tma-from-infill.complex.input.json`
**Output**: `generate-tma-from-infill.complex.output.json`

Description: Converts a curving infill segment (10 positions, courses 175 to 20 degrees) into a TMA segment with high course variance warning and reduced opacity styling.

### Edge Case: Single Position

**Input**: `generate-tma-from-infill.edge-1.input.json`
**Output**: `generate-tma-from-infill.edge-1.output.json`

Description: Rejects an infill segment with only 1 position, returning an `insufficient_data` error.

### Edge Case: Wrong Segment Type

**Input**: `generate-tma-from-infill.edge-2.input.json`
**Output**: `generate-tma-from-infill.edge-2.output.json`

Description: Rejects a segment of type PLAN (not INFILL), returning an `invalid_input` error.
